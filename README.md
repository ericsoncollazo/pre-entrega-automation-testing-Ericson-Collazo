# Pre-Entrega Automation Testing - Ericson Collazo

## Propósito del Proyecto
Este proyecto contiene la automatización de pruebas para la plataforma **SauceDemo** utilizando Python y Pytest, implementando buenas prácticas de pruebas de software.

## Tecnologías Utilizadas
* **Python** (Lenguaje de programación)
* **Pytest** (Framework de pruebas)
* **Selenium WebDriver** (Automatización del navegador)
* **Google Chrome** (Explorador)
